# **Whisper Audio Transcription Tool with Timestamps**

A lightweight Python tool that uses **OpenAI Whisper** to automatically transcribe audio files and convert them into **English text with timestamps**.
Supports:

* Transciption
* SRT-style timestamp formatting
* Simple Python script (no complex setup)

---

## 🚀 **Features**

* 🎙️ **Automatic speech-to-text transcription**
* 🌐 **Translates to English** using Whisper
* ⏱️ **Generates timestamps for every spoken line**
* 📄 **Exports clean text / SRT-style transcript files**
* 🧠 Powered by OpenAI Whisper model (`tiny`, `small`, `base`, `medium`, or `large`)
* 🧰 Lightweight & easy to integrate into any workflow

## 🧠 **How It Works**

* Loads the Whisper model (`small` by default)
* Converts the audio waveform to text
* Translates automatically (if audio is non-English)
* Extracts each segment’s `start` and `end`
* Writes them in SRT-style format

---

## 💡 **Sample Code (transcribe.py)**

```python
import whisper
import os

# Load the model
model = whisper.load_model("small")

# Paths
audio_path = r"samples/india_1.mp3"
output_path = r"outputs/transcript-india_1-english.txt"

# Transcribe with translation
result = model.transcribe(audio_path, task="translate")

# Make sure outputs folder exists
os.makedirs("outputs", exist_ok=True)

# Save transcript with timestamps
with open(output_path, "w", encoding="utf-8") as f:
    for i, segment in enumerate(result["segments"]):
        start = segment["start"]
        end = segment["end"]
        text = segment["text"]

        f.write(f"{i+1}\n")
        f.write(f"{start:.2f} --> {end:.2f}\n")
        f.write(f"{text}\n\n")

print("\n✅ Transcription completed!")
print(f"Saved as: {output_path}")
```
